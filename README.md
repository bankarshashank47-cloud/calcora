# Calcora

A fast, private, responsive online calculator built with plain HTML, CSS and JavaScript.

## Features

- Addition, subtraction, multiplication, division and operator precedence
- Parentheses, decimals, percentages and positive/negative values
- Long-number and scientific-notation display
- Division-by-zero and malformed-expression protection
- Calculation history with reuse, deletion and clear-all
- Memory: M+, M−, MR, MC
- Undo/redo, copy and shareable calculation links
- Keyboard and numpad support
- Light/dark theme persistence
- Responsive mobile-first UI
- Semantic HTML, ARIA labels, visible focus states and reduced-motion support
- No external JavaScript dependencies or tracking

## GitHub Pages

This repository is designed to run as a static GitHub Pages site. Enable Pages for the `main` branch with the root folder.

## Privacy

Calcora has no analytics, advertising SDK, account requirement or third-party tracking. History is stored locally in the browser when local storage is available.
